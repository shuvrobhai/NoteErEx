# NoteErEx 0.1.0

_Released 2026-09-20_

Initial release of NoteErEx (নোটের এক্সটেনশন), bringing fast, offline first web clipping to markdown with YAML frontmatter directly to your browser.

## Highlights

- **Full article clipping**: Save clean, ad-free web articles to markdown with YAML frontmatter using Mozilla Readability.
- **Selected text clipping**: Highlight any text passage on a web page and export only that excerpt with source metadata.
- **Keyboard shortcut**: Press `Alt+Shift+C` (or `Command+Shift+M` on macOS) to clip active pages or selections instantly without clicking the popup.
- **Obsidian and Logseq ready**: Output includes structured frontmatter with title, author, date, and reading time for note taking tools.

## Improvements

- Compact 380 pixel popup interface adapting automatically to light and dark system themes.
- Real time preview cards displaying article metadata, estimated reading time, and word count before download.
- Reliable downloads using UTF-8 data URLs routed through the background service worker, preventing cancelled downloads when the popup unmounts.
- Automatic filename sanitization ensuring cross platform filesystem safety.

## Upgrade notes

Initial release. Load the unpacked `.output/chrome-mv3` build into Chrome via `chrome://extensions` with Developer Mode enabled.
